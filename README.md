Esquisse is an interactive node-based tool for visualizing and designing workflows. Drag tools and devices onto a canvas, connect them by protocol, and map out how software and hardware communicate in your setup.

## Features

- 🎛️ 35+ software tools and hardware devices from the SAT's ecosystem, and others
- 🔌 Protocol-aware connections (OSC, MIDI, Audio Stream, NDI, and more)
- 🏷️ Filter tools by protocol to quickly find what's compatible
- 💾 export/import .esquisse projects
- ↩️ Undo/redo with Cmd/Ctrl+Z
- 📱 Mobile support: tap to add nodes to the canvas
- ✏️ Custom tool and device creation
